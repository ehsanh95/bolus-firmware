2. Uplink Decoder

Decodes the exact firmware wire contract: Telemetry V2 on FPort 2 or configuration ACK/NACK on FPort 4.

Telemetry V2 must be exactly 32 bytes. ACK/NACK must be exactly 8 bytes.
Telemetry V2 quick map
BytesField
0Version/message header: current summary = 0x21
1–2Sequence, little-endian
3RuntimeConfig version
4Status/validity flags
5–7Battery % and mV
8–15Temperature current/min/max/negative excursion
16–22Episode, pulse, inter-pulse, MPU burst counts
23–28Quantized MPU features
29–30Reserved classifier candidate counts
31Event/reference flags — not CRC
Firmware sources of truth: App/Services/telemetry_codec.c, App/Services/downlink_management_service.h, and App/Config/bolus_lorawan_credentials.h. Keep this toolkit and the network-server decoders synchronized whenever the wire protocol changes.
